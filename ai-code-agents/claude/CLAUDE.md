# Global Claude Instructions

This directory holds the shared Claude Code configuration for this repository:
agents, commands, skills, settings and hooks. The setup script links this file
to the global instructions path, so this short note is all it carries.

Personal global instructions are kept privately by each person and are not
versioned here. Add your own rules there, or in a project's own CLAUDE.md, not
in this file.

For what the shared hooks, skills and agents do and how they reach a session,
see `README.md` in this directory and the pages under `docs/context/` at the
repository root (start with `docs/context/INDEX.md`).
